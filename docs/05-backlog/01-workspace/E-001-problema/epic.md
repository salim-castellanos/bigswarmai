# Épica E-001 — Un problema que se puede retomar

El operador abre una carpeta, deja ahí el objetivo y lo que el enjambre ya descubrió, y puede cerrar la ventana sin perderlo.

## Por qué este módulo

Dominio. La carpeta no es el código de BigSwarmAI.

## Features

| Feature | Outcome |
| --- | --- |
| F-001 | La carpeta se reconoce y guarda el objetivo |
| F-002 | El tablero solo acepta un descubrimiento que alimenta al resto |
| F-003 | Se puede listar, buscar y leer la carpeta |
| F-004 | El enjambre arranca en el nodo elegido |
| F-005 | El panel de la extensión configura y muestra ese árbol |

## Fuera de la épica

Entrenar modelos. Cuentas de varios operadores. Un servicio que siga gastando con la ventana cerrada.

## Runbook

`docs/07-runbooks/001-ventana/runbook.md` cubre F-001, F-002 y F-003. F-004 queda en backlog.
